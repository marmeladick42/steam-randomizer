# Steam Randomizer

Приложение для Windows (Electron) и сайт, который можно запустить на своём компьютере: выбирает случайную игру из Steam по подробным фильтрам. Оформлено в тёмной теме Steam с розово-красной подсветкой.

## Команды

Один раз после скачивания проекта: `npm install`.

| Команда | Что делает |
| --- | --- |
| `npm start` | Запускает приложение для компьютера (Electron). |
| `npm run serve` | Запускает сайт на этом компьютере: http://localhost:3000. Нужен `server.env` с ключом (см. [Сайт](#сайт-доступ-по-ссылке)). |
| `npm run share` | То же, что `serve`, плюс Cloudflare Tunnel: в консоли появится ссылка `https://….trycloudflare.com`, по которой сайт откроется у кого угодно. |
| `npm run check` | Проверка на живом Steam API: фильтры, поиск, режим библиотеки. Ключ не нужен. |
| `npm run dist` | Собирает портативный `dist/SteamRandomizer.exe` и `SHA256SUMS.txt`. |
| `npm run dist:installer` | Собирает установщик `dist/SteamRandomizer-Setup.exe` и `SHA256SUMS.txt`. |
| `node scripts/checksums.mjs` | Заново считает `SHA256SUMS.txt` для файлов в `dist/`. |

Остановить `start`, `serve` или `share` можно сочетанием Ctrl+C в консоли.

## Сайт: доступ по ссылке

Интерфейс тот же, что у приложения, но запросы к Steam выполняет Node-сервер на вашем компьютере (`web/server.js`). Ключ Steam API хранится только на сервере. Посетители получают готовые результаты, а ключ не увидят ни на странице, ни в запросах, ни в инструментах разработчика.

### 1. Ключ

Скопируйте `server.env.example` в `server.env` и впишите ключ (где его взять — https://steamcommunity.com/dev/apikey):

```
STEAM_API_KEY=ваш_ключ_из_32_символов
```

`server.env` добавлен в `.gitignore`, и сервер его не отдаёт: наружу доступны только файлы из `renderer/`. Вместо файла можно задать переменные окружения, у них приоритет. Другие настройки в файле:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | порт сервера |
| `HOST` | `127.0.0.1` | `127.0.0.1` — сайт доступен только с этого компьютера и через туннель; `0.0.0.0` — ещё и из локальной сети |
| `STEAM_REGION`, `STEAM_LANGUAGE` | `us`, `russian` | регион и язык (интерфейса, описаний и меток: `russian`, `english`, `ukrainian`) для новых посетителей |

Приложение для компьютера этот файл не использует: его ключ хранится отдельно, в зашифрованном виде (см. ниже). Ключ проверяется при запуске сервера; если он не подходит, сервер не запустится.

### 2. Ссылка

1. Один раз установите cloudflared: `winget install --id Cloudflare.cloudflared`, затем откройте новое окно терминала.
2. `npm run share`, после чего скопируйте ссылку из консоли. Она появляется не сразу, обычно через 10–30 секунд: сначала скрипт проверяет, что адрес уже открывается через публичный DNS (1.1.1.1). Если открыть свежую ссылку раньше, DNS провайдера может на время запомнить, что такого домена нет, и ссылка будет казаться нерабочей. Если так всё же случилось, помогут `ipconfig /flushdns` и несколько минут ожидания, либо DNS `1.1.1.1` / `8.8.8.8` в настройках сети. Если адрес не заработал за 3 минуты, скрипт всё равно покажет ссылку с предупреждением. Вывод самого `cloudflared` можно включить переменной `TUNNEL_DEBUG=1`.

Ссылка работает, пока открыта консоль и включён компьютер. При каждом запуске ссылка новая. Порты на роутере открывать не нужно, ваш IP посетителям не виден, HTTPS включён автоматически. Постоянный адрес на своём домене можно получить через именованный туннель Cloudflare (нужен домен в Cloudflare), он настраивается в `cloudflared` отдельно. Если `cloudflared` установлен не в `PATH`, укажите путь к нему в переменной `CLOUDFLARED`.

### Как устроена веб-версия

- **Настройки у каждого посетителя свои.** Профиль Steam, регион и язык хранятся в браузере посетителя (localStorage) и передаются с каждым запросом. Ввода и удаления ключа на сайте нет.
- **Режим «Библиотека»** работает, только если у профиля посетителя открыта «Игровая информация».
- **Ограничения**, чтобы никто не исчерпал дневной лимит ключа (около 100 000 запросов): не больше 8 поисков и 40 запросов профиля или меток в минуту с одного IP, и не больше 4 поисков одновременно на весь сервер. Реальный IP посетителя сервер берёт из заголовков `cloudflared`.
- **«Открыть в Steam»** передаёт ссылку `steam://` клиенту Steam посетителя. Если клиент не установлен, подойдёт кнопка «В браузере».
- Страница рассчитана на экран шириной от 1024 px, на телефонах её придётся прокручивать.

## Ключ Steam API в приложении для компьютера

Если ключа нет, при запуске открывается экран ввода с пошаговой инструкцией (ключ получают на https://steamcommunity.com/dev/apikey).
Ключ проверяется запросом к Steam и сохраняется в зашифрованном виде (Electron `safeStorage`, на Windows — DPAPI, привязка к учётной записи пользователя) в файл `%APPDATA%/Steam Randomizer/secrets.json` — всегда в профиле пользователя, никогда рядом с `.exe`. Путь виден на экране ввода ключа и в настройках, в интерфейсе показываются только последние 4 символа ключа.

- Файл `secrets.json`, скопированный на другой компьютер или под другого пользователя, не расшифруется: приложение удалит его и попросит ввести ключ заново.
- Если шифрование в системе недоступно (не Windows, нет keyring), ключ на диск не пишется и живёт только до закрытия приложения — интерфейс об этом предупреждает.
- Ключ из `.env` старых версий при первом запуске автоматически переносится в `secrets.json` и удаляется из `.env`.

Остальные настройки (не секретные) лежат в `.env`:

```
STEAM_ID=7656119...        # необязательно, для режима «Библиотека»
STEAM_REGION=us            # регион магазина (валюта)
STEAM_LANGUAGE=russian     # язык интерфейса, описаний и меток: russian, english или ukrainian
```

Где лежит `.env`: при `npm start` — в папке проекта; в собранном `.exe` — рядом с ним (если туда нельзя писать — в `%APPDATA%/Steam Randomizer`).

## Проверка целостности

После каждой сборки в `dist/` создаётся `SHA256SUMS.txt` (формат `sha256sum`) — его нужно публиковать вместе с `.exe`. Пользователь проверяет скачанный файл так:

```
certutil -hashfile SteamRandomizer.exe SHA256
```

или в PowerShell: `Get-FileHash SteamRandomizer.exe`. Полученное значение должно совпасть (без учёта регистра) со строкой для этого файла в `SHA256SUMS.txt`. Хеш меняется с каждой сборкой, поэтому в репозитории он не хранится. Пересчитать вручную: `node scripts/checksums.mjs`.

## Подпись сборки

Без сертификата сборка проходит как обычно, но без подписи (в логе будет предупреждение `no code signing certificate configured`). Чтобы подписать `.exe`, задайте переменные окружения — в консоли или в файле `electron-builder.env` в корне проекта (он в `.gitignore`, electron-builder читает его сам). Подписываются и портативный лаунчер, и внутренний `SteamRandomizer.exe`. Нужен один из вариантов:

| Вариант | Переменные |
| --- | --- |
| Azure Trusted Signing | `AZURE_SIGN_ENDPOINT`, `AZURE_SIGN_ACCOUNT`, `AZURE_SIGN_PROFILE`, `WIN_SIGN_PUBLISHER` + `AZURE_TENANT_ID`, `AZURE_CLIENT_ID`, `AZURE_CLIENT_SECRET` |
| Сертификат в хранилище Windows (USB-токен или облачный HSM через KSP: DigiCert KeyLocker, SSL.com eSigner и т.п.) | `WIN_SIGN_CERT_SHA1` (отпечаток) или `WIN_SIGN_CERT_SUBJECT` |
| Облачный HSM со своей утилитой (jsign и т.п.) | `WIN_SIGN_COMMAND` — команда подписи, `{file}` заменяется на путь к файлу |
| Файл `.pfx`/`.p12` (только старые сертификаты: с июня 2023 ключи OV/EV выдаются только на HSM) | `WIN_CSC_LINK` (путь или base64), `WIN_CSC_KEY_PASSWORD` |

Необязательные: `WIN_SIGN_PUBLISHER` (имя издателя как в сертификате), `WIN_SIGN_TIMESTAMP_URL` (сервер меток времени, по умолчанию DigiCert). Конфигурация — в `electron-builder.cjs` (electron-builder 26: `win.signtoolOptions` / `win.azureSignOptions`). Проверить подпись: `signtool verify /pa /v "dist\Steam Randomizer 1.0.0.exe"` или «Свойства → Цифровые подписи».

Портативный шаблон electron-builder содержит `CRCCheck off`, и штатно (через `nsis.include`) это не отменить — пользовательские include для portable не подключаются; целостность обеспечивает Authenticode-подпись.

## Режимы

- **Магазин** — весь каталог Steam. Метки, платформы, язык, режимы игры, скидки, Steam Deck и VR фильтрует сам поиск Steam. Затем случайные страницы результатов проверяются по остальным фильтрам: доле положительных отзывов и их количеству, году выхода, цене в валюте региона, размеру скидки и контенту 18+.
- **Библиотека** — ваши игры (нужен профиль Steam и открытая «Игровая информация»). Дополнительно можно отфильтровать по времени в игре: «не играл», «меньше / больше N часов».

Фильтр «Исключить игры из моей библиотеки» в режиме магазина тоже использует профиль.

## Структура

```
main.js              главный процесс, IPC, настройки, перенос ключа из старого .env
preload.js           безопасный мост к интерфейсу (contextBridge)
web/server.js        веб-сервер: отдаёт renderer/, API для браузера, лимиты запросов
web/api.js           window.api для браузера (вместо preload.js)
web/share.js         сервер + Cloudflare Tunnel (npm run share)
server.env.example   образец настроек веб-сервера
lib/steam.js         запросы к Steam Store и Web API, кэш
lib/randomizer.js    фильтры и выбор случайной игры
lib/env.js           чтение и запись .env
lib/secrets.js       зашифрованное хранилище ключа API (safeStorage)
renderer/            интерфейс (HTML/CSS/JS без фреймворков)
scripts/smoke-test.js проверка на живом API (npm run check)
scripts/checksums.mjs SHA256SUMS.txt после сборки
scripts/sign-command.js подпись внешней командой (WIN_SIGN_COMMAND)
electron-builder.cjs конфиг сборки и подписи (.cjs, а не .js: иначе cmd запустит его вместо CLI)
```
