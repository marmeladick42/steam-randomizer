Подключение к Steam

Для работы нужен ваш личный Steam Web API Key. Он сохраняется локально в зашифрованном виде средствами Windows, привязан к вашей учётной записи и никуда не отправляется, кроме серверов Steam.

Шифрование недоступно в этой системе: ключ будет храниться только до закрытия приложения, после перезапуска его придётся ввести снова.

Как получить ключ

  1. Войдите в Steam в браузере Аккаунт не должен быть «ограниченным»: на нём должна быть хотя бы одна покупка или пополнение от $5. Нужен подключённый Steam Guard.
  2. Откройте страницу регистрации ключа
  3. Укажите любой домен Например localhost — для этого приложения домен не важен.
  4. Примите условия и нажмите «Регистрация» Steam может попросить подтвердить действие в мобильном приложении Steam Guard.
  5. Скопируйте ключ Это строка из 32 символов в поле «Ключ». Вставьте её слева и нажмите «Проверить и сохранить».
Никому не передавайте ключ. С ним можно действовать от имени вашего аккаунта через Web API. Если ключ утёк — на той же странице нажмите «Отозвать мой ключ API».
Для режима «Библиотека» в настройках приватности профиля Steam параметр «Игровая информация» должен быть «Открытый».
